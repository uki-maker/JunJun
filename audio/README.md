# 音声ファイル設定

このフォルダに支払い音の音声ファイルを配置してください。

## 対応フォーマット
- MP3 (.mp3)
- WAV (.wav) 
- OGG (.ogg)
- M4A (.m4a)

## ファイル命名規則
- 日本語ファイル名：支払い音1.mp3、支払い音2.mp3 など
- 英数字ファイル名：payment1.mp3、payment2.mp3 など

## 推奨仕様
- 長さ：1-3秒程度
- ファイルサイズ：100KB以下
- 音量：適度な大きさ（大きすぎない）

## 設定方法
js/config.js で音声ファイルの設定を行います。
音声ファイルを追加したら、config.jsのsounds配列にファイル名を追加してください。
